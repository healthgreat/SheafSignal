## Convergent fatal findings (across reviews)

1. **Methods novelty is mathematically thin.** The "rank-one cellular sheaf"
   with ℝ stalks and ±1 restrictions is the trivial sheaf on a graph and adds
   no expressive power over a weighted directed graph + node potentials.
   (R1.F1, R1.F2; **confirmed at code level by R4.F1**: the unit test
   `test_cellular_sheaf_residual_matches_legacy_mismatch` literally asserts
   `sheaf_residual ≡ flow_z − pathway_gradient_z`.)

2. **The synthetic ground-truth benchmark is circular by construction.**
   `simulate.py:87-125` defines "inconsistent" edges as exactly those where
   LR flow opposes pathway gradient, and SheafSignal scores edges by that
   residual; AP=1.00 is tautological. No fair baseline (e.g.,
   `flow_z * pathway_gradient_z`) is included. (R1.F3, **confirmed at code
   level by R4.F2**.)

3. **No positive biological demonstration on any of the five datasets.**
   Cross-dataset behaviour produces five different "top frustration sources"
   with no biological pattern explained by the method itself. (R2.F1)

4. **The "10,000-permutation confirmatory subset" reports p-values at the
   resolution floor and is post-hoc rather than pre-registered.** Code in
   `stats.py:227` uses `(ge + 1) / (completed + 1)`; with `completed = 10000`
   and zero null exceedances, `p ≡ 9.999e-05` mechanically. (R3.F1; **R4.F5
   adds**: silent `except ValueError: continue` skips failed permutations
   without logging, and the result table has no `null_at_or_above_observed`
   column.)

5. **The CAF/Fibroblast vs Myeloid p-value flip in GSE154778 is not
   diagnosed.** Sample-level leave-one-sample-out is missing. (R3.F2, R2 §3)

6. **Public-release reproducibility cannot be verified from the previous
   bundle.** Internal inconsistency between dashboard (blocked) and distance
   report (ready) plus 4 of the 4 release-audit reports missing. (R3.F5)
   **R4 adds code-level evidence**: 5 production scripts hardcode
   `D:\secrets\…` and `D:\BioSoft\…` as defaults, breaking clean-clone on
   non-Windows. `pyproject.toml` lists 8 authors but Han Yan has no email,
   while the audit reports `AUTHOR_CONFIRMATION_READY`.
