# Manuscript workspace

Suggested title:

> SheafSignal identifies inconsistency, feedback, and frustration in
> multicellular communication networks

Core figures for a high-impact methods manuscript:

1. Conceptual model:
   - ligand-receptor communication as sheaf-valued graph flow
   - local consistency, curl, harmonic circulation, frustration
2. Simulation benchmark:
   - recovery of gradient, curl, and harmonic components under known ground truth
   - robustness to dropout, sparsity, and annotation noise
3. Public scRNA-seq benchmark:
   - comparison with CellChat, CellPhoneDB, NicheNet, LIANA, and niche-DE
   - SheafSignal adds network consistency information not reported by standard
     edge-level communication tools
4. Spatial transcriptomics case study:
   - spatially local frustration hotspots
   - tissue-region-specific feedback loops
5. Biological discovery and validation:
   - disease-relevant communication frustration source
   - independent dataset validation
   - experimental or literature-backed validation

A manuscript targeting very high-impact journals needs a strong biological
story, not only a new metric. The method must reveal a previously missed
mechanism or resolve a known contradiction in tissue communication biology.
