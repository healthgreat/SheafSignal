# Ethics And Data Use Statement

Draft pending corresponding-author confirmation:

This study is a computational methods and benchmarking analysis based entirely
on publicly available processed scRNA-seq and spatial transcriptomics datasets
listed in `metadata/datasets.tsv`. No new human participant samples were
collected, no new intervention was performed, and no individual-level private
clinical data were generated by this work.

All public datasets remain subject to their original repository terms, licenses,
and data-use restrictions. The GitHub repository must not redistribute
controlled-access raw reads, private clinical metadata, or any data prohibited
by the original data providers. Large processed benchmark objects should be
released through the final Zenodo archive after DOI minting.

The corresponding authors should confirm whether the target journal requires a
formal institutional review board exemption statement for secondary analysis of
publicly available de-identified data.
