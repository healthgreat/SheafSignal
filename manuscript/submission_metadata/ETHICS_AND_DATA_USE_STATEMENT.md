# Ethics And Data Use Statement Draft

This SheafSignal benchmark uses public processed scRNA-seq and spatial
transcriptomics datasets listed in `metadata/datasets.tsv`. No new human
participant data were generated by this computational analysis.

Raw public datasets remain subject to their original repository terms,
licenses, and controlled-access boundaries. The repository must not redistribute
controlled-access raw reads or private clinical metadata.
