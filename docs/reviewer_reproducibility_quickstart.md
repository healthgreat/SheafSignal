# Reviewer Reproducibility Quickstart

Timestamp: 2026-05-03 01:25:00 +08:00

## Purpose

This guide gives reviewers a short, reproducible path for checking that
SheafSignal runs from a clean checkout and that the manuscript-facing claims are
generated by documented workflows.

It intentionally separates:

- demo checks that require only Git-tracked files;
- public-data checks that require GEO or 10x downloads;
- release checks that require a public GitHub URL and Zenodo DOI.

## Scope Boundary

SheafSignal is a computational methods workflow. The demo and public-data
commands below test software behavior, graph-consistency outputs, and
manuscript provenance. They do not validate clinical utility, treatment
prediction, or causal tumor biology.

## Environment

Recommended minimal local environment:

```bash
python --version
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

For stricter reproduction, use the pinned lock file:

```bash
pip install -r envs/requirements-py311-lock.txt
pip install -e .
```

## Check 1: Demo Run From Tracked Files

This check does not require downloading any large public datasets.

```bash
sheafsignal run \
  --expression examples/demo_expression.csv \
  --metadata examples/demo_metadata.csv \
  --lr-db examples/demo_ligand_receptor.csv \
  --gene-set examples/demo_pathway_genes.txt \
  --project-dir .
```

Expected outputs:

```text
results/sheaf_energy_by_edge.csv
results/hodge_decomposition_scores.csv
figures/communication_curl_network.pdf
```

## Check 2: Demo Run With Permutation Statistics

```bash
sheafsignal run \
  --expression examples/demo_expression.csv \
  --metadata examples/demo_metadata.csv \
  --lr-db examples/demo_ligand_receptor.csv \
  --gene-set examples/demo_pathway_genes.txt \
  --project-dir . \
  --n-permutations 100 \
  --random-seed 1
```

Expected additional outputs:

```text
results/sheaf_energy_permutation_pvalues.csv
results/frustration_permutation_pvalues.csv
results/global_permutation_pvalues.csv
```

Interpretation boundary: demo p values are smoke-test evidence only. They are
not manuscript biological evidence.

## Check 4: Public Data Download Validation

This check verifies the dataset manifest and download plan without downloading
large matrices.

```bash
python scripts/download_public_datasets.py --validate-only
python scripts/download_public_datasets.py --dry-run
```

The authoritative public-data manifest is:

```text
metadata/datasets.tsv
```

## Check 5: One Real Public Dataset After Download

After the GSE154778 processed GEO file is downloaded, run:

```bash
python scripts/prepare_public_datasets.py \
  --dataset-id gse154778_pdac_scrna \
  --force

python scripts/run_tme_benchmark.py \
  --dataset-id gse154778_pdac_scrna \
  --manuscript-grade
```

For a local smoke subset:

```bash
python scripts/prepare_public_datasets.py \
  --dataset-id gse154778_pdac_scrna \
  --max-cells 1000 \
  --force

python scripts/run_tme_benchmark.py \
  --dataset-id gse154778_pdac_scrna \
  --n-permutations 20
```

Interpretation boundary: the GSE154778 Myeloid signal is a computational,
annotation-dependent hypothesis unless all claim gates pass. Sparse cell types
must remain supplementary or QC-only.

## Check 6: Release And Claim Audits

```bash
python -m pytest -q
ruff check scripts tests
python scripts/release_audit.py
python scripts/check_release_metadata_placeholders.py
python scripts/check_final_submission_blockers.py --report-only
```

Expected current pre-release status before public GitHub and Zenodo:

```text
RELEASE_METADATA_BLOCKED_EXTERNAL_IDENTIFIERS
NATURE_METHODS_GO_NO_GO_REPORT.md decision: NO_GO
```

This is expected until a real public GitHub URL and Zenodo DOI are inserted.

## Check 7: Clean Export Preflight

```bash
python scripts/run_clean_clone_preflight.py
```

This exports the current Git-tracked tree to a temporary clean directory and
runs lightweight reproduction checks from tracked files only.

Interpretation boundary: this is stronger than testing a dirty working tree,
but it is still not a substitute for final public-GitHub clean-clone
reproduction after the DOI and release URL are real.

## Reviewer Checklist

Before treating the manuscript as submission-ready, verify:

- public GitHub repository URL exists;
- immutable Git tag and release URL exist;
- Zenodo DOI is minted and inserted into `metadata/datasets.tsv`;
- final public clean-clone reproduction passes;
- claim-safety audit has no blocking overclaiming rows;
- journal metrics, CAS zone, and warning-list status are checked on submission
  day;
- all author-owned metadata and ethics/data-use wording are confirmed.

## Safest Reviewer-Facing Novelty Statement

SheafSignal implements a domain-specific sheaf/Hodge workflow that converts
CCC-derived ligand-receptor observations and pathway-state transitions into
edge- and node-level graph-consistency residuals.
